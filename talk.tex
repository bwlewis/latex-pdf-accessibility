\section*{Why \LaTeX?}
\vspace{2em}
\begin{itemize}
\item \LaTeX$\,$  is the de facto standard for the communication and publication of math and science.
Chances are you \emph{will} encounter \LaTeX in STEM!
\item \LaTeX$\,$  is widely used in publishing because it clearly separates presentation from content.
\item \LaTeX typesets technical symbols and mathematics beautifully.
\end{itemize}
\end{minipage}
}

\section*{Why Accessibility?}
\vspace{2em}
The Department of Justice established \textbf{April 24th, 2026} as the compliance deadline for the updated
Title II regulations of the Americans with Disability Act.\\[1em]

\emph{All} course materials in Canvas, Blackboard, and other LMS platforms must be accessible to students with disabilities.\\[1em]

Regulations require compliance with \href{https://www.w3.org/TR/WCAG21/}{WCAG 2.1 AA Accessibility Standards}.
\end{minipage}
}

\hspace{4em}
\scalebox{1.8}{%
\begin{minipage}{0.5\textwidth}
\vspace{4em}
\section*{Why Accessibility?}
\vspace{2em}
The real reason: \textbf{It's the right thing to do!}\\[1em]

Lots of us have difficulty reading/understanding/processing digital media. We must strive to make concepts presented digitally
accessible to everyone. Difficulty reading or understanding digital content is an unnecessary barrier to learning.

\end{minipage}
}

\section*{Step 1: Use \texttt{lualatex}}
\vspace{2em}
\begin{itemize}
\item \LaTeX$\,$ can be processed by many different rendering engines (\texttt{pdflatex}, \texttt{lualatex}, $\ldots$)
\item \texttt{lualatex} is currently the best engine to use for accessibility.
\item On many GNU/Linux systems simply install with:
\item[] \texttt{sudo apt install texlive-luatex}
\end{itemize}
\end{minipage}
}

\vspace{4em}
\section*{Step 2: Metadata in your documents}
\vspace{2em}
Add the following to the very top of your document (adjusting \texttt{lang} as needed):\\

\texttt{\textbackslash{DocumentMetadata}\{ \\
\phantom{x}  tagging=on, \\
\phantom{x}  tagging-setup=\{math/setup=\{mathml-SE,mathml-AF\},math/alt/use\}, \\
\phantom{x}  pdfstandard=ua-2, \\
\phantom{x}  pdfstandard=a-4f, \\
\phantom{x}  lang=en-US \\
\}
}\\

This turns on tagging and embeds two kinds of mathematical notation markup for widest compatibility with reader software
\emph{and} adds LaTeX-based alt-text tags to images for older readers that can't understand MathML.
\end{minipage}
}

\vspace{4em}
\subsection*{Use the \texttt{unicode-math} math symbol package}
\vspace{2em}
Include the following package in your document preamble:\\

\texttt{\textbackslash{usepackage\{unicode-math\}} \\
}\\

\emph{Avoid} use of the following packages if possible (\texttt{unicode-math} may work in their place):

\strikethroughminipage{0.3\textwidth}{
{\texttt{\textbackslash{usepackage}\{amsmath\}}}\\
{\texttt{\textbackslash{usepackage}\{amssymb\}}}
}\\

This may not be strictly necessary but tends to produce good embedded MathML output.\\
BREAKING NEWS, as of Spring, 2026 amsmath should work OK!

\end{minipage}
}

\vspace{4em}
\subsection*{Be sure to add text descriptions to every included image}
\vspace{2em}
Whenever you include an image in your document, be sure to add a text description with
\texttt{alt}. For example:\\[1em]

\texttt{\textbackslash{includegraphics}[alt=\{Image description\}, width=\textbackslash textwidth]\{filename\}
}

\end{minipage}

\section*{Setting up NVDA reader software with MathCAT}
\vspace{2em}
\begin{itemize}
\item The reader software with the most complete support is NVDA (NV Access)
equipped with the MathCAT add-on. It's free, supports audible and braille
output in many languages, and works very well!
\item[] \url{https://www.nvaccess.org/download/}
\item[]
\item Install NVDA from the above link$\ldots$
\end{itemize}
\end{minipage}
}



\newpage

\hspace{4em}
\scalebox{1.8}{%
\begin{minipage}{0.5\textwidth}
\vspace{4em}
\begin{itemize}
\item Bring up the NVDA menu and select ``Add-on store$\ldots$'' from the ``Tools'' menu.
\item Right-click on the ``MathCAT: speech and braille from MathML'' add-on and select ``Install''
You will see ``Downloaded, pending install'' in the Status column. (This can take a while.)
\item You'll be asked to re-start NVDA for the add-on to take effect.
\end{itemize}

You're all set to read beautiful PDF documents with \LaTeX$\,$ math aloud or in braille!\\

We recommend using Microsoft Edge to view PDF documents to be read by NVDA---it
worked fine for us! Firefox also worked. Weirdly, Google Chrome's
PDF viewer didn't work well with NVDA on our Windows 11 computer.\\

As an alternative, Adobe Acrobat Reader should also work.

\end{minipage}
}

\section*{Issues}
\vspace{2em}
\begin{itemize}
\item These techniques are all \emph{very} new! Most (all?) accessibility
checkers don't completely work yet. That includes, at least to some extent, Blackboard's Ally
built-in checker as of January 2026 (which only understands alt-text equation image tags
and does not understand embedded MathML yet).
\item \emph{Most} \LaTeX$\,$ packages ``just work.'' Your mileage may
vary however with less mainstream packages. If you run into issues you might
need to consider package changes.
\item As mentioned in the last slide, choice of PDF viewer and
reader compatibility can be finicky.
We expect fewer glitches as the software matures.
\end{itemize}
\end{minipage}
}
